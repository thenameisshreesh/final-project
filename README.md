# Simple Interest Calculator

A simple Bash script that calculates **simple interest** from the values you enter.

## Purpose
This project is part of my Git and GitHub final project. It shows how to create a GitHub repository with the standard files (LICENSE, README, CODE_OF_CONDUCT, CONTRIBUTING) and a working shell script.

## Formula
```
Simple Interest = (Principal x Rate x Time) / 100
```
- **Principal**: the starting amount of money
- **Rate**: the yearly interest rate (in %)
- **Time**: the number of years

## How to Use
1. Clone the repository:
```bash
   git clone https://github.com/dikshachavan3205/github-final-project.git
   cd github-final-project
```
2. Make the script executable:
```bash
   chmod +x simple-interest.sh
```
3. Run it:
```bash
   ./simple-interest.sh
```
4. Enter the principal, rate and time when asked.

## Example
```
Enter Principal amount:
1000
Enter Rate of interest:
5
Enter Time (in years):
2
Simple Interest = 100
```
